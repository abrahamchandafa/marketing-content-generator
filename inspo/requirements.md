Marketing Content Generator 
Build a small full-stack application that generates posters with the information entered by a 
user.  
For example, a user would provide (1) brand name, (2) product name, (3) product description, 
and (4) price. The application should use this information to produce an image poster and return 
that to the user. 
Please find an example in the last page. You can find more examples in the Template.zip 
Tech Stack 
● Frontend: React with TypeScript 
● Backend: Express with Node.js or Flask with Python 
● Data storage: Your choice 
You may use AI coding tools or other development tools of your choice. You should be able to 
explain, debug, and modify everything you submit. 
Please approach the exercise as a small production-ready codebase.  
Required Functionality 
The user should be able to: 
1. Enter: 
○ Product Name 
○ Brand Name 
○ Product Description 
○ Price 
2. Submit the information for generation. 
3. See the generation status. 
4. View the generated marketing poster. 
5. View previous generations. 
The application should include appropriate validation, loading states, error handling, and 
responsive behavior. 
Acceptance Criteria 
We should be able to: 
● Run the application using the README. 
● Submit valid marketing information. 
● See a processing or loading state. 
● See the generated result without manually refreshing. 
● View previous generation history. 
● Receive useful validation messages for invalid input. 
● Receive a useful error message when something goes wrong. 
● Use the main workflow on desktop and mobile screen sizes. 
Submission 
Submit a Git repository or ZIP file containing: 
● The application source code 
● A short README.md covering: 
○ How to run the application 
○ Key technical decisions 
○ Known limitations 
○ What you would improve with more time 
○ Any AI tools used and how you used them 
Deployment is not required.
